 Online Quiz System
A responsive web-based quiz application developed using HTML, CSS, and JavaScript.

 Features
- Student name, department, and year selection
- Multiple-choice questions
- 30-second timer for each question
- Question counter
- Progress bar
- Correct and wrong answer indication
- Automatic score calculation
- Percentage and Pass/Fail result
- Answer summary
- Print result option
- Restart quiz
- Responsive design

Technologies Used

- HTML5
- CSS3
- JavaScript
